# Two Truths and a Lie

## Play the game

https://maxhfel.github.io/Day14_Forms/

## How to play

1. Enter your first name, last name and age, then click **SUBMIT**.
2. Try the warm-up trivia question.
3. In the Two Truths and a Lie section, click **START**.
4. You have 10 seconds to pick which statement is the lie and click **SUBMIT**.
5. If time runs out, your answer is submitted automatically.

## Features

- Text and number inputs for introductions
- Radio inputs for the trivia question and the game
- Countdown timer using `setInterval()` and `clearInterval()` (Extra challenge #3A)
